# Audio assets and licensing

All 23 files in `public/audio/` are **original synthesised placeholders** generated by `scripts/gen-placeholder-audio.ts` (`npm run audio:gen`). No third-party material, so no external license applies; the project owner may release them under any terms. They are placeholders: replace with produced audio under the same ids (`src/features/runtime/sounds.ts`). When replacing, record source, author and license per file in a table here.

Behavior (unit-tested with a fake backend; **not** heard in a browser): separate master/ambient/music/sfx volumes, persisted in localStorage; audio starts only after a user gesture; one ambient loop at a time; pauses when hidden; max 8 simultaneous sfx.
