# Οδηγός διαχειριστή (Admin guide)

- Είσοδος: `/admin` με λογαριασμό Supabase Auth που έχει ρόλο admin.
- Δημιουργία ιστορίας: νέο προσχέδιο → δωμάτια, αντικείμενα (hotspots), γρίφοι, ενδείξεις, κινηματογραφικές σκηνές.
- Έλεγχος: ο validator μπλοκάρει τη δημοσίευση με σφάλματα (π.χ. άλυτος γρίφος, ελλιπή assets).
- Δημοσίευση: δημιουργεί αμετάβλητη έκδοση. Τρέχοντα παιχνίδια συνεχίζουν στην έκδοση που ξεκίνησαν· νέα παιχνίδια παίρνουν την τελευταία.
- Αρχειοθέτηση: η ιστορία φεύγει από τη βιβλιοθήκη, τα ενεργά παιχνίδια συνεχίζονται.
- Δεν υπάρχει UI διαχείρισης χρηστών· οι admin ορίζονται στη βάση.
