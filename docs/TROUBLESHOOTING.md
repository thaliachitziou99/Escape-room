# Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Πιθανή αιτία | Ενέργεια |
|---|---|---|
| Ο κωδικός σύνδεσης δεν δουλεύει | Έληξε (5 λεπτά) ή κλείδωσε (5 λάθη) | Νέα συνεδρία από την τηλεόραση |
| Το κινητό δείχνει «Αποσύνδεση» | Δίκτυο / ύπνος συσκευής | Αυτόματη επανασύνδεση· αν μείνει, ανανέωση σελίδας (το παιχνίδι διατηρείται) |
| Χαμένο κινητό | — | Από την τηλεόραση «Αποσύνδεση χειριστηρίου», σύνδεση νέου |
| Δεν ακούγεται ήχος | Το πρόγραμμα περιήγησης θέλει κίνηση χρήστη | Πάτημα οπουδήποτε στην οθόνη· έλεγχος έντασης στις Ρυθμίσεις |
| 429 σφάλματα | Rate limit | Αναμονή 1 λεπτό |
| 409 στην έναρξη | Η ιστορία δεν είναι δημοσιευμένη | Δημοσίευση από το admin |
| Build σφάλμα | Πρώτο πραγματικό build δεν έχει γίνει ακόμη | Διόρθωση τύπων/imports |
